GAMEPAD BRIDGE / 电脑端

Xbox / PS5 输入，映射成 Switch 手柄。

手柄先连接 Windows。网页读取手柄后，经 USB-UART 把操作送到 ESP32；结束录制后可命名并选择保存槽位。

键位绑定

点击左侧 Xbox 键位，再点击右侧 Switch 键位进行绑定。

INPUT 01Xbox Wireless
OUTPUT 01Nintendo Switch

摇杆圆盘显示实时方向和幅度：点击圆盘绑定方向，点击圆心 L3 / R3 绑定按下键。主键和分享键能否被网页读取取决于浏览器与驱动。

等待 Xbox 手柄。当前输出：中立

持续推住同一方向会合并成一个动作；画圈按所选间隔采样轨迹。录制停止后预览草稿，取名并选择槽位保存，动作数量按可用存储空间决定。

GAMEPAD BRIDGE / 宏录制

请用电脑浏览器连接 Xbox 或 PS5 手柄。

手柄输入映射与录制需要桌面版 Chrome 或 Edge 的 Gamepad API，以及连接到电脑的 USB-UART。手机可浏览宏并控制板载宏。

GEAR CHECK / 双链路

两根线，各干一件事。

原生 USB 负责扮演手柄；手机连板载 Wi-Fi 热点即可控制，电脑也可用 USB-UART。

  1. 01
    原生 USB → Switch 底座

    GPIO19 / GPIO20 输出有线手柄 HID。

  2. 02
    Wi-Fi → 手机 / USB-UART → 电脑

    手机连接 ESP32-S3-Switch 后打开 http://192.168.9.1；电脑可继续用串口网页。
